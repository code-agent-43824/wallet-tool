# HANDOFF

**Незавершённой работы нет.** Четыре правки по указанию владельца закрыты: `_layout_` у
ctypes-структур, пин вендорных архивов по SHA-256, PIN из stdin, версия в коде. Все четыре
workflow зелёные, логи прочитаны.

Открыт один пункт, никем не взятый и требующий решения владельца — порядок обновления
вендорной библиотеки после появления пина по SHA-256, см. конец `docs/PLAN.md`.

**Важно для следующего агента:** ни одна из правок не проверялась на реальном кошельке —
устройства нет. Особенно это касается `_layout_`: ошибка в раскладке не падает, а тихо
сдвигает поля в вызовах к вендорной библиотеке, и мок-тесты её не поймают.
