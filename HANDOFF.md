# HANDOFF

**В работе:** перенос новых библиотек `wtpkcs11ecp` из переданного владельцем архива на
статический сервер и перевод CI с GitHub Release на прямые версионированные URL.

Дерево версии `2.18.2.0` опубликовано и проверено по HTTPS; загрузчик, тесты и три workflow
переведены на прямые URL с закреплёнными SHA-256. Локально 92 теста проходят. Следующий шаг —
после push прочитать фактические логи CI Linux, macOS и Windows, убедиться, что каждый
артефакт содержит новую библиотеку, и лишь затем удалить четыре старых бинарных ZIP из
релиза `3rdparty`.

Открытые пункты, никем не взятые, — в конце `docs/PLAN.md`: подтверждение для `--force`,
подпись ключами `ed25519`, BIP39-passphrase, порядок обновления вендорной библиотеки.
Первые три отложены владельцем сознательно, начинать их без его слова не нужно.

**Отдельно:** ничего из операций с токеном не проверялось на реальном кошельке —
устройства нет. В первую очередь это касается смены кривой: ключи, созданные прежними
версиями утилиты, остались на `secp256r1`, и одна и та же мнемоническая фраза до и после
правки даёт разные ключи. Мок-тесты этого не покажут.
